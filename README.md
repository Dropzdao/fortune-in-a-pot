A make.fun competition entry: a Python program that writes one kind, funny fortune for a houseplant to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```

Entry (105 characters):

> Soon the sun will choose your newest leaf first, and the whole windowsill will pretend not to be jealous.
